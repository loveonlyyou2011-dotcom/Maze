# 아이들 놀이터

유치원~초등학생을 위한 모바일 놀이터 앱입니다. 홈 화면에서 3가지 놀이 중 하나를 골라 즐길 수 있습니다.

## 놀이 종류

### 🧭 손가락 미로 탐험
- 테마 8종: 우주 🚀 · 바다 🐠 · 공룡 🦕 · 동물농장 🐮 · 자동차 🚗 · 사탕나라 🍭 · 정글사파리 🦁 · 겨울나라 ⛄
- 난이도 6단계 (유치원 ~ 초등 고학년)
- 시간 제한 없음, 손가락으로 길을 그으며 통과. 완료 기록은 별점(⭐)과 최고 기록으로 저장
- 도착 시 컨페티 애니메이션 + 효과음, 캐릭터가 손가락(트레일 끝)을 따라다님

### 🔢 숫자 놀이
- 덧셈 · 뺄셈 · 곱셈 · 나눗셈, 각각 난이도 6단계
- 답 입력 방식 2가지 지원: 객관식 버튼 / 숫자 키패드 직접입력 (게임 중 언제든 전환 가능)
- 한 라운드 8문제, 실수 횟수에 따라 별점(⭐1~3) 부여

### 🗣️ 단어 놀이
- 언어 3종: 영어 🇬🇧 · 일본어 🇯🇵 · 중국어 🇨🇳
- 주제 4종: 동물 · 색깔 · 숫자 · 음식 (각 8단어)
- 카드모드(플래시카드로 훑어보기) / 퀴즈모드(객관식 8문제) 선택 가능
- 브라우저 내장 음성합성(Web Speech API)으로 단어 발음을 들려줌 (기기에 해당 언어 음성이 없으면 조용히 건너뜀)

## 공통
- 시간 제한 없음, 완료 기록은 별점(⭐)과 최고 기록으로 저장 (브라우저 localStorage, 기기별로 별도 저장됨)
- 우측 상단 🔊 버튼으로 전체 효과음 음소거 가능
- 빌드 도구 없이 `index.html` 파일 하나로 동작

## 로컬에서 확인하기
`index.html` 파일을 더블클릭하거나, 모바일 화면 크기로 브라우저에서 열어 확인하세요.

## GitHub Pages로 배포하기
1. GitHub에 새 저장소를 만듭니다 (예: `maze-game`).
2. 이 폴더 내용을 저장소에 올립니다.

```bash
git init
git add index.html README.md
git commit -m "손가락 미로 탐험 게임 추가"
git branch -M main
git remote add origin https://github.com/<사용자명>/<저장소명>.git
git push -u origin main
```

3. GitHub 저장소 페이지에서 **Settings → Pages**로 이동합니다.
4. **Source**를 `main` 브랜치, 폴더는 `/ (root)`로 설정하고 저장합니다.
5. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 게임이 실행됩니다.

## 커스터마이징

- `LEVELS` 배열에서 각 단계의 미로 크기(`cols`, `rows`)를 조절해 난이도를 바꿀 수 있습니다.
