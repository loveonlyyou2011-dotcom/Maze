# 아이들 놀이터

유치원~초등학생을 위한 모바일 놀이터 앱입니다. 홈 화면에서 원하는 놀이를 골라 즐길 수 있고, 온 가족이 함께 쓸 수 있는 여행 회화 기능도 들어있습니다.

## 놀이 종류

### 🧭 손가락 미로 탐험
- 테마 8종: 우주 🚀 · 바다 🐠 · 공룡 🦕 · 동물농장 🐮 · 자동차 🚗 · 사탕나라 🍭 · 정글사파리 🦁 · 겨울나라 ⛄
- 난이도 6단계 (유치원 ~ 초등 고학년)
- 시간 제한 없음, 손가락으로 길을 그으며 통과. 완료 기록은 별점(⭐)과 최고 기록으로 저장
- 도착 시 컨페티 애니메이션 + 효과음, 캐릭터가 손가락(트레일 끝)을 따라다님

### 🔢 숫자 놀이
- 덧셈 · 뺄셈 · 곱셈 · 나눗셈, 각각 난이도 6단계
- 답 입력 방식 2가지 지원: 객관식 버튼 / 숫자 키패드 직접입력 (게임 중 언제든 전환 가능)
- 한 라운드 8문제, 실수 횟수에 따라 별점(⭐1~3) 부여

### 🗣️ 단어 놀이
- 언어 4종: 한글 🇰🇷 · 영어 🇬🇧 · 일본어 🇯🇵 · 중국어 🇨🇳
- 주제 5종: 동물(69) · 색깔(44) · 숫자(1~100) · 음식(69) · 자음·모음(24, 한글 전용)
  - 자음·모음은 한글을 아직 못 읽는 아이를 위한 기초 단계로, 한글을 배울 때만 표시됩니다.
  - 동물·음식은 실제 이모지가 있는 항목 위주로 최대한 폭넓게 구성했습니다.
  - 숫자는 1~100까지 전부 있으며, 단어 자체를 규칙(십의자리+일의자리 등)에 따라 자동 생성해 정확도를 높였습니다. 한글은 유치원에서 먼저 배우는 고유어 수 표현(하나·둘·스물하나…)을 사용합니다.
  - 색깔은 실제로 구분되는 색 이름 자체가 한정적이라 크레파스 48색 세트에 가까운 44개로 구성했습니다 (동물/음식만큼 늘리기는 어려운 항목입니다).
- 놀이 방식 4종
  - 🗂️ 카드로 배우기: 플래시카드로 훑어보기
  - 🎯 퀴즈 풀기: 객관식 8문제
  - 🧩 짝맞추기: 카드 12장(6쌍)을 뒤집어서 그림-단어 짝 찾기 (메모리 게임)
  - 🔗 줄긋기: 그림과 단어를 손가락으로 이어서 연결하기
- 브라우저 내장 음성합성(Web Speech API)으로 단어 발음을 들려줌 (기기에 해당 언어 음성이 없으면 조용히 건너뜀)
- 🔁 복습하기: 숫자 놀이/단어 놀이에서 틀렸던 문제만 모아서 다시 풀 수 있는 모드. 맞히면 목록에서 사라지고, 다시 틀려도 벌점 없이 계속 도전 가능

### 🏆 스티커판
- 미로/숫자/단어 놀이에서 모은 별을 한곳에 모아보는 성취감 화면
- 총 별 개수에 따라 배지(🥉🥈🥇🏆)가 붙음

### ✈️ 여행 회화
- 언어를 먼저 고르고, 여행 순서에 맞춘 12개 상황을 선택하면 각 상황별 10문장이 한 화면에 나열됩니다.
  1. 이미그레이션 → 2. 유심 구매 → 3. 호텔까지 이동 → 4. 호텔 체크인 → 5. 여행지 예약 → 6. 식당 주문·결제 → 7. 화장실 찾기 → 8. 티켓 구매 → 9. 투어 상품 문의 → 10. 체크아웃·짐 보관 → 11. 공항 가는 법 → 12. 비행기 티켓팅
- 문장마다 한국어 뜻 + 현지어 문장 + 한글 발음 표기(예: "How are you?" → "하우 아 유")를 함께 보여줘서, 외국어를 모르는 어르신이나 아이도 그대로 소리 내어 따라 읽을 수 있습니다.
- 🔊 버튼으로 실제 발음(Web Speech API)도 들을 수 있습니다.
- 지원 언어 8종: 영어 🇺🇸 · 일본어 🇯🇵 · 중국어(간체) 🇨🇳 · 중국어(번체, 대만) 🇹🇼 · 태국어 🇹🇭 · 베트남어 🇻🇳 · 스페인어 🇪🇸 · 인도네시아어 🇮🇩
  - 이 언어들은 번역 정확도와 기기 발음 지원을 신뢰할 수 있는 범위로 선정했습니다. 다만 문장·발음 표기는 AI가 직접 작성한 것이라, 실제 여행 전에는 원어민이나 다른 자료로 한 번 더 확인하시길 권장합니다.

### 🎨 색칠놀이
- 오리지널 캐릭터 8종 + 단어놀이 그림 8종(SVG) 외에, AI로 그린 선그림 10개 카테고리(동물·바다 생물·공룡·교통수단·과일·채소·곤충·우주·꽃과 식물·학용품·장난감, 총 230여 장)를 카테고리 → 그림 목록 순서로 골라 색칠할 수 있습니다.
  - 특정 브랜드 캐릭터(디즈니·핑크퐁·티니핑·또봇 등)는 저작권 문제로 넣을 수 없어, 같은 느낌을 살린 오리지널 디자인/공개 소재로 대체했습니다.
- 24색 팔레트 + 🧹 지우개 + ✨ 마스터 색(탭하면 그 영역이 선택한 색으로 바로 채워짐)
- 손가락으로 문지르듯 칠하는 방식으로, 지나간 자리만 색이 채워집니다
- AI로 생성한 선그림은 검은 윤곽선을 기준으로 흰 영역을 자동으로 나눠(flood-fill) SVG 그림과 똑같이 색이 삐져나가지 않도록 만들었습니다

## 공통
- 시간 제한 없음, 완료 기록은 별점(⭐)과 최고 기록으로 저장 (브라우저 localStorage, 기기별로 별도 저장됨)
- 우측 상단 🔊 버튼으로 전체 효과음 음소거 가능
- 홈 화면에 매일 연속 놀이 기록(🔥 n일 연속)이 표시됨
- 빌드 도구 없이 `index.html` 파일 하나로 동작

## 로컬에서 확인하기
`index.html` 파일을 더블클릭하거나, 모바일 화면 크기로 브라우저에서 열어 확인하세요.

## GitHub Pages로 배포하기
1. GitHub에 새 저장소를 만듭니다 (예: `maze-game`).
2. 이 폴더 내용을 저장소에 올립니다.

```bash
git init
git add index.html README.md
git commit -m "손가락 미로 탐험 게임 추가"
git branch -M main
git remote add origin https://github.com/<사용자명>/<저장소명>.git
git push -u origin main
```

3. GitHub 저장소 페이지에서 **Settings → Pages**로 이동합니다.
4. **Source**를 `main` 브랜치, 폴더는 `/ (root)`로 설정하고 저장합니다.
5. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 게임이 실행됩니다.
